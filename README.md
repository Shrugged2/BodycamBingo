# Bodycam Bingo

A browser-based 5x5 bingo board. Each new game randomly selects 24 unique phrases from the full phrase pool and keeps **FREE SPACE / Swears at Cop** in the center.

## Files

- `index.html` - the website, layout, and game behavior
- `squares.js` - the editable phrase pool

Keep both files in the same folder. Open `index.html` to play locally, or upload both files to the root of a GitHub Pages repository.

## Controls

- Click or tap any square, including the free space, to toggle its green mark.
- **New Board** draws a fresh set of 24 phrases and clears marks.
- **Reset Marks** clears the current marks without changing the board.

The current board and marks are saved in the browser so a page refresh does not interrupt a game.
